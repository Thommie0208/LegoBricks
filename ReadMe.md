# Lego Power Bricks

Adds multiple power bricks from the Lego games to Hollow Knight in the form of charms.
The added bricks are:

- 2x, 4x, 6x, 8x and 10x geo multiplier bricks
- Remove hardfall
- Increase nail damage by 2x
- Regenerate health
- Increase health
- Free gathering swarm
- Reduce cost to cast Vengeful Spirit/Shade Soul

Currently you can only give yourself these bricks using the 'Give all charms' button in Debug, but I'm planning on adding overworld locations eventually.
